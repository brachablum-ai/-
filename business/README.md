# הסוכנים של ברכה בתנועה — מדריך שימוש

הסוכנים עוזרים לשווק חוגי תנועה למעונות יום לגיל 0–3: מוצאים מעונות, כותבים פניות, בונים הצעות, מתכננים שיעורים ועוקבים שאף מעון לא נשכח.

## איך מפעילים
פותחים סשן חדש ב-Claude Code (באפליקציה או ב-claude.ai/code) על הריפו הזה, וכותבים בעברית רגילה. אפשר לציין את שם הסוכן או פשוט לבקש, ו-Claude יבחר את הסוכן המתאים.

| הסוכן | מה הוא עושה | דוגמה לבקשה |
|---|---|---|
| **daycare-researcher** חוקרת מעונות | מוצאת מעונות בעיר ובונה רשימת לידים מדורגת | "תחקרי מעונות יום בגן יבנה" · "הנה הטבלה מהעלון של העירייה, תשלימי את הרשימה" |
| **outreach-writer** כותבת פניות | תסריט טלפון, וואטסאפ, מייל, מעקב, דף מידע | "תכיני לי פנייה לדובדבן הסירה" · "מה להגיד בטלפון לגן אשכולית?" |
| **proposal-builder** בונה הצעות | הצעת תוכנית ומחיר למעון או לרשת | "תכיני הצעה לרשת המעונות של המתנ"ס" |
| **lesson-planner** מתכננת שיעורים | מערכי שיעור לפי כיתה וחג, ותוכנית שנתית | "מערך חנוכה לפעוטות, 20 דקות" · "תוכנית שנתית לתינוקייה" |
| **leads-manager** מנהלת לידים | מעדכנת סטטוסים, "מה עושים היום", סיכום שבועי | "דיברתי עם ליטף, ביקשו הצעה" · "למי לחזור היום?" |

## שגרה שבועית מומלצת
1. **ראשון בבוקר:** "למי לחזור השבוע?" (leads-manager).
2. **לפני כל שיחה:** "תכיני לי פנייה ל..." (outreach-writer).
3. **אחרי כל שיחה:** מספרים מה קרה במשפט אחד (leads-manager).
4. **מי שביקשה הצעה:** proposal-builder. **מי שאמרה כן:** lesson-planner.
5. **פעם בחודש:** "תחקרי עיר נוספת" (daycare-researcher): גן יבנה, רחובות, אשדוד, קריית עקרון, מזכרת בתיה.

## הקבצים
- `profile.md` — **פרטי העסק. כדאי להשלים קודם את כל השדות `[להשלים]`** (מחירים, טלפון, אישור משטרה, ביטוח). הסוכנים לא ממציאים פרטים, ולכן כל מה שחסר שם יופיע אצלם כחסר.
- `research/` — דוחות מחקר לכל עיר. כרגע: יבנה.
- `leads/` — רשימות לידים (נפתחות באקסל ובגוגל שיטס).
- `outreach/`, `proposals/`, `lessons/` — מה שהסוכנים כותבים.

## חשוב לדעת
- **הריפו ציבורי.** כל אחד יכול לראות את הקבצים ב-GitHub, ולכן לא שומרים בו שמות וטלפונים אישיים, מחירים שסוכמו עם לקוחות או התרשמויות. הסוכנים יודעים את זה. אם רוצים לשמור הכל במקום אחד, אפשר להפוך את הריפו לפרטי, אבל אז לבדוק שאחסון האתר ממשיך לעבוד.
- **גישה לאינטרנט:** נוצרה סביבת עבודה בשם **"brachablum-ai research"**, שמאפשרת לסוכן החוקר לגשת לאתרי מדריכים. כדאי לבחור בה כשפותחים סשן חדש. חלק מאתרי העירייה והמתנ"ס חוסמים שרתים מחו"ל, ולכן אם יש קובץ מהעירייה, הכי טוב לפתוח אותו בעצמך ולהדביק לסוכן.
- **שמירה:** אחרי עדכונים, לבקש מ-Claude: "תשמור ותעלה לגיט".
